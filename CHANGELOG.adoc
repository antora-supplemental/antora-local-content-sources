= Changelog

== [0.2.4] - 2026-10-20

=== Changed

* Visible progress before slow work: stderr + logger banners explaining disk search (why/what/how), cache-only fast path, D binary download, and elapsed time when search completes.

== [0.2.3] - 2026-10-20

=== Added

* Interactive confirmation before disk search when cache paths are missing/invalid (TTY). Env `ANTORA_LOCAL_SOURCES_CONFIRM_SEARCH=yes|no` bypasses the prompt for scripts; bypass text is included in the question for agent/LLM use.
* Skip D/MFT when all remotes still validate from cache.

== [0.2.2] - 2026-10-20

=== Changed

* **Canonical marker:** fixed filename `.antora-source-id` with stable `id:` + `url:` lines in the body (id is not encoded in the path). MFT / walks search that basename only, then read files to match.
* Hash filenames `.antora-src-*` are deprecated but still honored when present.
* Cache / report use `markerId` (32 hex); cache format version 2.

== [0.2.1] - 2026-10-20

=== Changed

* Windows drive-wide search defers to D resolver NTFS **MFT** scan (`searchMethod: auto`); Node skips parallel drive walks on win32.
* Warn when D resolver is missing on Windows (MFT volume pass skipped).

== [0.2.0] - 2026-10-20

=== Added

* Search order: playbook directory first, then ancestors (excluding already-searched child subtrees, capped by `maxUpwardHops`), then `searchRoots`, then other drives in parallel (Node worker threads; D `std.parallelism`).
* Duplicate clone detection: logs every match; build continues with the first ordered hit unless overridden.
* Gitignored overrides file `.antora-local-sources.yml` (see `.antora-local-sources.example.yml`) — pin by HTTPS URL or `.antora-src-*` marker basename.
* Auto-download `antora-source-resolver` from GitHub Releases into `build/.antora/bin/` (`dAutoDownload`, `dRelease`, `dRepo` config).
* Env `ANTORA_LOCAL_SOURCES_SEARCH_DRIVES=0` disables cross-drive search (tests / fast iteration).

=== Changed

* Default `searchRoots` no longer includes playbook parent; upward search covers that path.

== [0.1.0] - 2026-10-19

=== Added

* Antora extension: resolve remote `content.sources` to local clones using stable `.antora-src-*` marker files (deterministic SHA-256 basename per normalized git URL).
* Search roots: playbook dir, `%code%` / `CODE_ROOT`, `~/code`, optional `searchRoots`; hive heuristic `github.com/{owner}/{repo}` when markers are missing.
* Cache under `build/.antora/local-content-cache.json`; writes `build/.antora/antora-playbook-local.generated.yml` for debugging.
* Optional `antora-source-resolver` D CLI integration (`dBinary` config).
* Legacy `.antora-source-id` (URL in file body) supported.
